## 1. 記法

プログラム `P` の 1 つの実行 `X` を固定する。`X` は段の列 `s_1, s_2, ...` である (D24)。

### 1.1 持ち手と持ち手の単位

**持ち手**とは D25 の 3 種 (生きている活性化・生きているオブジェクト・環境) をいう。

オブジェクトが持つ参照を数える単位を**持ち手の単位**と呼ぶ。オブジェクト `o'` の持ち手の単位は、
`o'` が `#ArrayStorage` のオブジェクトであれば `0` から `size - 1` の各要素の位置と、その要素の型の
`boxed_leaf_paths` が列挙する leaf との対であり、そうでなければ `o'` が保持する値の boxed leaf (D4)
である。

持ち手の単位が**書かれた**とは、(α) か (β) がそこへ参照を入れた後であることをいう。

この読みが A5 と D24 に当たること -- 書かれた単位のうちどれが参照を持ち、割り当てられた直後の単位が
参照を持たないこと -- は `<1>0b` が述べる。

### 1.2 素動作

D24 は 1 つの段を不可分な動作の有限列へ分解し、その動作を 6 種に分ける -- 参照の受け渡し、生成、
割り当て、処分、解放、グローバル化である。この 6 種を**素動作**と呼び、D24 の並びの順に (α) から
(ζ) の名を付ける。受け渡しが (α)、生成が (β) であることは D24 が自分でそう呼んでいる。

- **(α) 受け渡し**: 1 つの参照が 1 つの持ち手を離れ、別の 1 つの持ち手に入る。`H` は変わらない。
  持ち手がオブジェクトであるときは、離れる側も入る側もそのオブジェクトの 1 つの持ち手の単位
  (第 1.1 節) である。
- **(β) 生成**: `Cnt` の元 `O` への参照が 1 つ新しく作られ、1 つの持ち手に入る。`H(O)` が 1 上がる。
  持ち手がオブジェクトであるときは、そのオブジェクトの 1 つの持ち手の単位が受け取る。
- **(γ) 割り当て**: 新しいオブジェクト `O` が `Obj` と `Cnt` に入る。`O` への参照が 1 つできて
  `H(O) = 1` となり、1 つの持ち手に入る。**割り当てられた直後の `O` の持ち手の単位は、参照を 1 つも
  持たない** (D24)。`O` の欄を埋める受け渡しは (α)、そこで新しく作られる参照は (β) であり、どちらも
  この動作とは別の素動作である。
- **(δ) 処分**: 1 つの持ち手が持つ `O` への参照が 1 つ無くなる。`H(O)` が 1 下がる。
- **(ε) 解放**: `H(o) = 0` である計数下のオブジェクト `o` について、`o` が持つ参照 (D25 の 2 番目の
  持ち手) をすべて処分し (指す先の `H` をそれぞれ 1 下げ)、`o` を `Obj` から取り除く。`o` は `Cnt` に
  留まる。
- **(ζ) グローバル化**: 計数下のオブジェクト `O` が `Cnt` を出て、グローバル状態になる (D26)。`O` は
  `Obj` に留まる。

**オブジェクトの記憶域への書き込みは素動作ではない** (D24)。書き込みは参照の勘定を動かさないので、
この文書はそれを数えない。切れ目の上の帰納が 6 種だけを場合に持てばよいことは `<1>0` が述べる。

### 1.3 段の中の素動作の順序

**段の中の素動作の順序は、その段の生成コードがその動作を行う順に取る。**

**(ε) が起こす解放は、その (ε) の後に置く。**この文書は、(ε) の処分で `H` が 0 になった
オブジェクトの解放を、その (ε) の**後**に置く。

**活性化が `Liv` に入る位置と出る位置も、この順序の中に取る。**活性化は、自分の初期 `Obl`
(D10 の初期値) を作る (α) の列の**直前**に `Liv` に入り、終端の `Ret` の消費を行う (α) の列の
**直後**に `Liv` を出る。どちらかの列が空のときは、それぞれ、その段が活性化を作る位置と、
終端の `Ret` の消費を行う位置を取る。`Liv` への出入りは素動作ではないので切れ目を作らない。

この 3 つの取り決めが D24 と D25 に当たることは `<1>0c` が述べる。

### 1.4 切れ目と点、そして量

- **切れ目** -- `X` の素動作を時間の順に一列に並べたときの、最初の素動作の前と各素動作の後の位置を
  いう。以下 `p` はつねに切れ目を渡る。切れ目が `p_0, p_1, ...` と列をなし、各切れ目の前にある
  素動作が有限個であることは `<1>9` が述べる。
- **段が終わる** -- その段が行う動作をすべて終えることをいう。節点の実行が終わることも同じ意味で
  いう。D31 が「ある段が終わらない」を発散の一形態として挙げる。
- **点** -- D24 が定める段内の点である。この文書の切れ目の列の上でそれがどの位置であるか -- 切れ目から
  「参照を処分する素動作と、その処分が起こす (ε) とのあいだ」を除いたものであること -- は `<1>0` が
  述べる。
- **時点** -- 段と段のあいだの点。`t_0` を `s_1` の前、`t_i` を `s_i` の後 (`i ≥ 1`) の点とする。
- **`Liv(p)`** -- 切れ目 `p` に生きている活性化 (D23) の集合。
- **`Obj(p)`** -- 切れ目 `p` に在るオブジェクトの集合。最初の切れ目 `p_0` (`= t_0`) での値は、環境が
  実行の最初の時点に持ち込んだオブジェクトの全体である (A17 (i-c))。以後は (γ) が入れ、(ε) が
  取り除く。この集合が各切れ目で D25 の「生きているオブジェクト」に一致することは `<1>0a` が示す。
- **`Cnt(p)`** -- 切れ目 `p` に計数下 (D26) であるオブジェクトの集合。(γ) が入れ、(ζ) が取り除く。
- 計数下オブジェクト `O` について:
  - `H_p(O)` -- `O` の参照カウント (D7)。
  - `A_p(O) := Σ_{a ∈ Liv(p)} (Obl(a) が持つ O への参照の個数)`。`Obl(a)` が `p` まで参照の多重集合
    として定まることは `<1>4a` が述べる。
  - `B_p(O) :=` 対 `(o', u)` の個数。ここで `o' ∈ Obj(p)`、`u` は `o'` の持ち手の単位 (第 1.1 節) で
    あって、`p` において `O` への参照を 1 つ持つものである。単位が参照を持ち始めるのは (α) か
    (β) がそれを書いた瞬間であり、持たなくなるのは、その参照が (α) で別の持ち手へ移るか、
    (δ) か (ε) で処分されるときである (`<1>0b`)。
  - `C_p(O) :=` `E` が持つ `O` への参照の個数 (D22)。
- **`INV(p)`** -- すべての `O ∈ Cnt(p)` について `H_p(O) = A_p(O) + B_p(O) + C_p(O)`。

`A`、`B`、`C` が D25 の 3 種の持ち手に 1 対 1 に対応することは `<1>1` が述べる。

### 1.5 別名類の帳簿と許容性

別名類 (D33) と `held` (D34) の量を、実行の切れ目の上で読む。**D34 は、`held` を段内の点でない
切れ目へ延ばしてよいと述べ、延ばす文書がその 3 つの箇条に従うことを求める。**次の 3 つは、D34 の
3 つの箇条の「段内の点」を「切れ目」に読み替えたものである。

- 計数下の別名類 `C` と切れ目 `p` について:
  - **`held_p(C)`** -- D34 の表が定める量を、次のとおり各切れ目へ延ばす。
    - 第 4・第 5・第 6 行の事象は、それを運ぶ素動作の直後の切れ目で `held` を動かす。1 つの素動作が
      複数の事象を運ぶことがある -- (ε) は `o` が持つ参照の処分をすべて 1 つの動作にまとめる -- ので、
      その切れ目では運ばれた事象の増減をすべて足す。
    - **第 1 行と第 2 行が置く開始値 1 は、その類の `ρ` 終端の leaf の参照が `Obl(a)` に入る素動作の
      直後の切れ目に置く。** 第 1 行ではその参照を作る素動作、第 2 行では活性化の初期 `Obl` を作る
      (α) の列のうちその leaf の分がそれである。
    - **第 3 行が置く開始値 1 は、活性化が `Liv` に入る切れ目に置く。** その 1 は呼び出し元が持つ
      参照であって `Obl(a)` に入らないので (D34)、`Obl` の側に相手となる素動作が無い。
  - **`β(C)`** -- `C` の `ρ` 終端が借用する (D14) パラメータ・capture の leaf であるとき 1、そう
    でないとき 0。
  - **`d_p(C) := held_p(C) - β(C)`** (A19 (i) の `d`)。
- **`S_{a,p}(O)`** -- 活性化 `a` の計数下の別名類のうち、`obj(C) = O` であり、開始の切れ目が `p` 以前で
  あるものの全体 (A19 (i) の `S`)。
- **`ADM(p)`** -- `p` に生きている各活性化 `a` と各 `O ∈ Cnt(p)` について
  `H_p(O) ≥ Σ_{C ∈ S_{a,p}(O)} d_p(C) + [S_{a,p}(O) に β(C) = 1 である類が在るならば 1]`。
  これが A19 (i) の不等式であり、D21 が活性化に課す制限である。
- **`p` まで許容的** -- `p` 以前 (`p` を含む) のすべての切れ目で `ADM` が成り立つこと。

この延長が D34 の 3 つの箇条に従い、段内の点でも時点でも D34 が定める値と一致すること、そして
すべての切れ目で `ADM` が成り立てば D21 の制限が満たされることは、`<1>0d` が述べる。

**`H` は実行の量である。** D7 が定める参照カウントはヒープの量であり、`H_p(O)` はそれである。D21 は
1 つの本体を見るとき `H` を活性化の側の与件として扱うが、実行を見るこの文書ではヒープの側の量として
読む。実行が作る各活性化について、その与件の側の `H` を実行の `H` に取ると D21 の制限が満たされる、
というのが P28 (b) である。

### 1.6 外部の結果

この文書の外の結果は、次の名前で引く。

- **EXT 自然数の帰納法** -- 自然数についての言明 `Φ` が `Φ(0)` を満たし、各自然数 `k` について
  `Φ(k)` から `Φ(k+1)` が出るならば、すべての自然数 `k` について `Φ(k)` が成り立つ。
- **EXT 有限木の上の帰納** -- 有限の根つき木について、各節点で「その子がすべて言明 `Φ` を満たすならば
  その節点も `Φ` を満たす」ことが示されているならば、その木のすべての節点が `Φ` を満たす。
- **EXT 排中律** -- 任意の命題 `Q` について、`Q` と `¬Q` の少なくとも一方が成り立つ。したがって
  `Q` から `R` が出て `¬Q` からも `R` が出るならば `R` が成り立ち (場合分け)、`Q` から `R` が出る
  ならば `¬R` から `¬Q` が出る (対偶)。
- **EXT 多重集合の分割** -- 有限多重集合 `M` の元が互いに区別されないとき、非負整数の族
  `(n_1, ..., n_r)` について、`n_1 + ... + n_r = |M|` であることと、`M` を `r` 個の部分多重集合へ
  分けて第 `i` 部分の濃度が `n_i` である分割が在ることとは同値である。
- **EXT 非負整数の和** -- 有限個の非負整数の和が 0 であるならば、その各項は 0 である。
